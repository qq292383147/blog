vue 自定义右键样式

2019-11-13 vue
主要是靠双击和右键来操作，可操作多个模态框，跟操作windows类似，接下来在里面拆出一个功能块来写一篇文章，就是自定义系统默认的右键。
自定义右键操作有五个步骤：
  1. 阻止默认右键。
  2. 获取当前右键点击时的x/y坐标，及id。
  3. 自定义右键菜单样式及内容，定位在指定的位置后显示。
  4. 返回对应点击目录的事件如:查看、删除、编辑。
  5. 在任何地方点击左键时隐藏右键菜单。
